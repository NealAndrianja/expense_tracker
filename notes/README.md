# Expense Tracker Learning Notes

This folder is the memory of the project. It records what I learn while rebuilding my React Native and Expo knowledge through practice.

The goal is not to document everything. The goal is to preserve the ideas, decisions, mistakes, and examples that will save me time later.

## Start here

1. Open [Learning journal](./00-learning-journal.md) to see the journey in chronological order.
2. Browse the topic folders when looking for a specific concept.
3. Use the [concept note template](./_templates/concept-note.md) when adding a reusable note.

## How notes should feel

Every note should be:

- **Skimmable:** the main idea is visible in a few seconds.
- **Practical:** it includes a small example or a connection to the app.
- **Personal:** it explains the idea in my own words, not as copied documentation.
- **Honest:** uncertainties and mistakes are worth recording.
- **Small:** one main concept per note.

## File naming

Use lowercase kebab-case names that say exactly what the note is about:

```text
use-state.md
expo-router-layouts.md
rendering-a-list-of-expenses.md
keyboard-hides-input.md
```

Avoid vague names such as `lesson-1.md` or `misc.md`.

## Project context

- Learning method: build first, study concepts when they become useful.
- App: an expense tracker that starts small and grows through iterations.
- Current stack: Expo SDK 57, React Native, React, TypeScript, and Expo Router.
- Documentation rule: prefer the exact [Expo SDK 57 documentation](https://docs.expo.dev/versions/v57.0.0/) for Expo-specific behavior.

## Our note-taking workflow

When I ask about a topic, we will normally:

1. Identify the smallest useful next task in the app.
2. Find the relevant official documentation or focused learning resource.
3. I study and implement it myself.
4. We clarify anything confusing.
5. The learning assistant writes a polished note in the appropriate folder.
6. We add a short journal entry linking to the note.

The assistant should explain and guide, but should not write application code unless I explicitly ask it to.
